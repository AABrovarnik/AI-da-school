# VibeCode START — программа для начинающих

Возраст: 10–14 лет. Продолжительность: 12 недель. Формат: 1 занятие в неделю по 60–90 минут + 30–60 минут самостоятельной практики.

## Результат курса
Ученик понимает цикл «идея → промпт → код → запуск → тестирование → исправление → улучшение» и создаёт собственный web-проект.

## Шаблон урока
1. Сегодня узнаем.
2. Объяснение простыми словами.
3. Небольшой пример.
4. Попробуй сам.
5. Спроси AI-наставника.
6. Мини-задание.
7. Проверка результата.
8. Завершение урока.

## Основные проекты
- персональная web-страница;
- «Угадай число»;
- викторина;
- генератор историй;
- собственный итоговый проект.

## Критерий успешности
Не знание синтаксиса наизусть, а способность поставить задачу, получить и понять решение AI, запустить его, найти ошибку и улучшить результат.
