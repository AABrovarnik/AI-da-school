# UI_SPEC.md

## Назначение
Спецификация интерфейса web-школы вайбкодинга для детей 10–14 лет.

## Принципы интерфейса
- светлый современный технологичный стиль;
- интерфейс не должен выглядеть слишком детским;
- крупные понятные кнопки и карточки;
- минимум визуального шума;
- адаптивность для desktop, laptop, tablet; mobile — чтение уроков и AI-чат;
- основная разработка проектов предполагается с клавиатурой.

## Навигация
Главная | Программы | Расписание | Уроки | Мои проекты | AI-наставник | Прогресс | Родителям | О школе

Для ADMIN дополнительно: Администрирование.

## Главная
Hero:
- заголовок: «Научись создавать сайты, игры и AI-приложения вместе с искусственным интеллектом»;
- подзаголовок: «Web-школа вайбкодинга для детей 10–14 лет»;
- CTA: «Начать обучение», «Посмотреть программы».

Блок «Как работает вайбкодинг»:
Придумал → объяснил AI → получил код → запустил → проверил → улучшил.

Карточки примеров проектов:
- личная web-страница;
- викторина;
- «Угадай число»;
- генератор историй;
- калькулятор;
- ToDo;
- приложение погоды;
- AI-ассистент;
- итоговый проект.

## Страница программы
Показывать:
- уровень START/PRO;
- длительность;
- число уроков;
- ожидаемые навыки;
- проекты курса;
- календарь;
- кнопку «Начать» / «Продолжить».

## Страница урока
Стандартная последовательность:
1. Сегодня узнаем
2. Объяснение
3. Пример
4. Попробуй сам
5. Спросить AI-наставника
6. Мини-задание
7. Проверить результат
8. Завершить урок

Обязательно показывать номер урока, название, прогресс и статус выполнения.

## Dashboard ученика
Блоки:
- приветствие;
- «Продолжить урок»;
- прогресс курса;
- текущий проект;
- следующее занятие;
- достижения;
- последние версии проектов.

## Мои проекты
ProjectCard:
- название;
- описание;
- дата обновления;
- превью;
- статус Idea / Development / Testing / Done;
- ссылка «Открыть»;
- версия.

На странице проекта:
- исходный код;
- превью;
- история версий;
- кнопка «Сохранить версию»;
- AI-помощь по текущему проекту.

## AI-наставник
Плавающая кнопка: «✨ Спросить AI-наставника».

Quick actions:
- 💡 Дай подсказку
- 🧒 Объясни проще
- 🔍 Найди ошибку
- 🧠 Задай мне вопрос
- 🚀 Как улучшить проект?
- 📝 Помоги написать промпт

Чат должен визуально отличать ответ наставника, код и подсказки.

## Прогресс
Показывать:
- процент курса;
- выполненные уроки;
- проекты;
- освоенные навыки;
- достижения.

Не использовать публичные стрессовые рейтинги.

## Родителям
Информационный раздел:
- чему учится ребёнок;
- чем вайбкодинг отличается от обычного программирования;
- безопасность;
- программа;
- календарь;
- руководитель школы.

Персональный прогресс доступен только авторизованному родителю/опекуну.

## Admin
CRUD-интерфейсы для:
Course, Module, Lesson, Assignment, ScheduleEvent, Student, Project, Achievement, Announcement.

Контент уроков хранить в данных/CMS, а не хардкодить в JSX.

## Design tokens
- border-radius: 12–20px;
- большие кликабельные зоны;
- контраст WCAG-friendly;
- ограниченная палитра;
- мягкие градиенты допустимы;
- анимации короткие и функциональные;
- не использовать мигание и навязчивые эффекты.

## Критерии приёмки UI
- все маршруты открываются;
- навигация не содержит битых ссылок;
- интерфейс читаем на 1366×768 и планшете;
- AI-чат доступен из урока;
- ученик видит текущий прогресс и проекты;
- важные действия не требуют более 2–3 кликов.
