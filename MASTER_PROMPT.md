# MASTER PROMPT — AI-da-school

Ты — lead full-stack developer, UX-архитектор и AI-интегратор. Твоя задача — создать в Google AI Studio полнофункциональное web-приложение **AI-da-school / VibeCode School** для обучения детей 10–14 лет вайбкодингу.

## Цель
Создать MVP web-школы с двумя учебными треками, личным кабинетом ученика, календарём, проектами, прогрессом и встроенным AI-наставником на Gemini.

## Обязательные источники требований
Перед разработкой изучи файлы репозитория:
- `docs/VibeCode_School_TZ_v1.0.md`
- `COURSE_START.md`
- `COURSE_PRO.md`
- `AI_TUTOR_PROMPT.md`
- `UI_SPEC.md`
- `DATABASE_SCHEMA.md`
- `SAFETY.md`
- `ROADMAP.md`

## Базовые параметры
- Возраст: 10–14 лет
- Язык: русский
- Руководитель школы: Броварник Александр Алексеевич
- Первый поток: 10.10.2026–26.12.2026
- Треки: VibeCode START и VibeCode PRO

## Технологии
- Frontend: React + TypeScript
- Backend: Node.js
- Gemini API только через server-side endpoint
- Secret: `GEMINI_API_KEY`
- Архитектура учебного контента: data-driven
- Подготовить проект к GitHub и дальнейшему deploy

## Обязательные разделы
Главная, Программы, Расписание, Уроки, Мои проекты, AI-наставник, Прогресс, Родителям, О школе, Администрирование.

## MVP Definition of Done
Ученик может открыть курс, пройти урок, сохранить прогресс, создать/редактировать проект, получить контекстную помощь AI и вернуться к работе позднее. Администратор может менять учебные данные без переписывания UI.

## Правило реализации
Не делай статический mockup. Реализуй рабочее приложение с demo-data, обработкой ошибок и адаптивным интерфейсом.

## Порядок работы
1. Проанализируй требования.
2. Покажи краткую архитектуру и файловую структуру.
3. Создай data models и seed data.
4. Реализуй navigation/layout.
5. Реализуй курсы, уроки, календарь и dashboard.
6. Реализуй проекты и прогресс.
7. Подключи AI-наставника через server-side API.
8. Реализуй safety guardrails.
9. Проверь responsive UX.
10. Выполни smoke-test всех маршрутов.
11. Исправь найденные ошибки.
12. Покажи working preview.

## Запреты
- Не помещай API key во frontend.
- Не hardcode каждый урок отдельной страницей.
- Не позволяй AI автоматически выполнять учебную работу вместо ребёнка без объяснения.
- Не собирай лишние персональные данные детей.

Сначала реализуй MVP. Функции из roadmap Phase 2/3 не должны блокировать запуск первой версии.
