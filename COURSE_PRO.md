# VibeCode PRO — углублённая программа

Возраст: 10–14 лет. Для выпускников START или учеников с базовым опытом. Продолжительность: 12 недель.

## Результат курса
Ученик умеет декомпозировать задачу, работать с React, JSON и API, использовать Git/GitHub, тестировать AI-код и создавать собственное AI/web-приложение.

## Ключевые навыки
- декомпозиция;
- компонентное мышление;
- state/props/events;
- JSON;
- REST API;
- server-side AI calls;
- Git/GitHub;
- отладка;
- тестирование крайних случаев;
- рефакторинг;
- многошаговые промпты.

## Итоговый проект
Примеры: AI-помощник школьника, образовательная игра, генератор контента, приложение с внешним API, персональный учебный dashboard.

## Критерий успешности
Ученик может объяснить архитектуру своего проекта, показать историю итераций и аргументированно рассказать, где AI помог, где ошибся и как результат был проверен.
