# School AI Admin Docs

Документация проекта админ-панели AI-администратора школы.

## Структура

- `docs/TZ/` — технические задания (утверждённые версии)
- `docs/decisions/` — архитектурные и продуктовые решения
- `docs/reports/` — отчёты по тестам, деплою, проверкам
- `docs/templates/` — шаблоны документов
- `docs/archive/` — устаревшие версии

## Правила версий

- Рабочие черновики ведутся в Obsidian.
- В репозиторий попадают только финальные версии.
- Формат имени файла: `YYYY-MM-DD_<topic>_vX.Y.md`
- Любое изменение финального документа = повышение версии (`v1.3 -> v1.4`).

## Текущий базовый документ

- `docs/TZ/2026-10-04_TZ_AI_admin_school_v1.3.md`

## Принцип хранения

- Obsidian — для заметок и подготовки.
- GitHub — источник истины и история изменений.
