# AI-da-school

Web-школа вайбкодинга для детей 10–14 лет с AI-консультантом.

**Руководитель школы:** Броварник Александр Алексеевич  
**Старт первого потока:** 10 октября 2026 года  
**Продолжительность:** 10–12 недель  
**Учебные треки:** VibeCode START и VibeCode PRO

## Документы

Основное техническое задание хранится в каталоге `docs/` в форматах Markdown и DOCX.

## Концепция

Цель проекта — научить детей превращать идею в работающий цифровой продукт вместе с AI: формулировать задачу, писать промпты, генерировать прототип, тестировать, находить и исправлять ошибки и развивать собственный проект.
