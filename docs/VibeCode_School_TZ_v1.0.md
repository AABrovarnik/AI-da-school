## 1. Концепция проекта

Создать современную интерактивную web-школу, в которой дети 10–14 лет изучают основы программирования и вайбкодинга через создание реальных небольших проектов при помощи AI.

Главный принцип:

> Не просто «учиться программировать», а придумывать идеи, формулировать задачу для AI, получать работающий прототип, проверять его, находить ошибки и постепенно улучшать собственный продукт.

Обучение должно сочетать:
- основы алгоритмического мышления;
- основы HTML/CSS/JavaScript;
- работу с AI;
- промпт-инжиниринг;
- вайбкодинг;
- тестирование и исправление ошибок;
- проектирование интерфейсов;
- основы безопасной работы в интернете;
- создание собственных web-приложений;
- презентацию готового проекта.

AI не должен полностью выполнять учебную работу вместо ребёнка. Его основная роль — наставник, объясняющий и подсказывающий следующий шаг.

## 2. Цели школы

Основная образовательная цель — научить ребёнка превращать идею в работающий цифровой продукт с помощью AI.

Целевая цепочка навыка:

**Идея → описание задачи → промпт → генерация → запуск → тестирование → ошибка → исправление → улучшение → публикация.**

Дополнительные цели:
- развивать логическое и проектное мышление;
- обучать грамотному взаимодействию с AI;
- объяснять, почему AI может ошибаться;
- формировать привычку проверять результат AI;
- знакомить с программированием без чрезмерного порога входа;
- переходить от простых игр и сайтов к самостоятельным приложениям.

## 3. Целевая аудитория

Основная группа — дети 10–14 лет.

Предполагается, что часть учеников:
- никогда не программировала;
- умеет пользоваться браузером;
- знакома с ChatGPT/Gemini на бытовом уровне;
- может не знать английской терминологии программирования;
- может не понимать устройство web-приложений.

Интерфейс и обучение должны быть максимально понятными и возрастно-уместными.

### Блок «Что такое вайбкодинг?»

Вайбкодинг — это способ создавать программы вместе с AI. Ученик рассказывает искусственному интеллекту, что хочет сделать, получает код, запускает его, проверяет результат и просит AI улучшить программу.

Схема:

**Придумал → объяснил AI → получил код → запустил → проверил → улучшил.**

## 14. Логика AI-наставника

AI не должен сразу выдавать полный ответ.

Последовательность:
1. Наводящий вопрос.
2. Подсказка.
3. Небольшой пример.
4. Разбор решения.
5. Полный код — только при необходимости или после нескольких попыток ученика.

## 15. System Prompt AI-наставника

Ты — AI-наставник школы вайбкодинга для детей 10–14 лет.

Твоя задача — помогать ученику самостоятельно понимать программирование и создавать проекты.

Говори дружелюбно, короткими понятными предложениями. Предполагается, что ученик может впервые видеть программный код.

Если используешь новый термин:
1. назови термин;
2. объясни его простыми словами;
3. покажи небольшой пример.

Не выполняй учебную работу полностью вместо ученика.

Сначала:
1. задай наводящий вопрос;
2. дай подсказку;
3. предложи проверить конкретное место;
4. покажи небольшой пример.

После этого, если ученик всё ещё не понимает, покажи решение и объясни его.

При анализе ошибки используй формат:
- Что произошло
- Почему это произошло
- Что проверить
- Как исправить

При работе с кодом объясняй, что именно было изменено.

Не проси ребёнка сообщать домашний адрес, номер телефона, пароль, данные банковских карт или другие конфиденциальные персональные сведения.

Не инициируй личное общение вне образовательной платформы.

Главная цель: **не написать программу вместо ученика, а научить ученика создавать программу вместе с AI.**

## 28. Безопасность детей

Обязательный принцип: **privacy by design**.

Не собирать данные, не необходимые для обучения. Минимизировать хранение даты рождения, адреса, телефона, геолокации и других персональных сведений детей.

Перед production-запуском отдельно провести юридическую проверку требований к обработке персональных данных несовершеннолетних.

## 29. Безопасность AI

- потенциально опасный контент;
- попытки обхода системного промпта.
