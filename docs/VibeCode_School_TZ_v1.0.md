## Учебные траектории

### VibeCode START
Для учеников, которые ранее практически не программировали. Цель — создать 4–6 небольших проектов и итоговое web-приложение.

### VibeCode PRO
Для учеников, прошедших START либо имеющих начальный опыт. Цель — создавать более сложные приложения, работать со структурированными данными, API, AI и React-компонентами.

## AI-наставник

AI-наставник должен помогать ребёнку самостоятельно понимать программирование. Последовательность помощи: наводящий вопрос → подсказка → небольшой пример → разбор → полное решение только при необходимости.

Быстрые действия: «Дай подсказку», «Объясни проще», «Найди ошибку», «Задай мне вопрос», «Как улучшить проект?», «Помоги написать промпт».

## Безопасность

Принцип **privacy by design**. Не собирать лишние персональные данные детей. Gemini API key хранить только на серверной стороне. Системный prompt не передавать клиенту. Перед production-запуском провести отдельную юридическую проверку обработки данных несовершеннолетних.

## Архитектура

Frontend: React + TypeScript. Backend: Node.js. Gemini API вызывается исключительно через server-side endpoint. Учебные материалы — data-driven, а не hardcoded.

Основные сущности: User, StudentProfile, ParentProfile, Course, Enrollment, Module, Lesson, LessonProgress, Assignment, Submission, Project, ProjectVersion, AIConversation, Achievement, ScheduleEvent, Notification.

Роли: STUDENT, PARENT, TEACHER, ADMIN.

## Критерии готовности MVP

Ученик может выбрать программу, открыть урок, видеть прогресс, выполнить задание, обратиться к AI-наставнику, создать и сохранить проект и позднее продолжить работу. Администратор может менять учебный контент без переработки интерфейса.
